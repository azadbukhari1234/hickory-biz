# Hickory Biz

Hickory Biz is a lightweight business website built with HTML and designed to present a brand, services, and contact information in a clean and professional layout.

## Overview

This project is a static website intended for business promotion and online presence. It is easy to customize, deploy on any static hosting service, and requires no complex build setup.

## Features

- Modern business-style landing page
- Responsive layout for desktop and mobile devices
- Clean and professional branding
- Simple structure for easy editing
- No framework or build tools required

## Tech Stack

- HTML5
- CSS3
- JavaScript (if used in the project)
- Static hosting compatible
- Azure static web app
